# Persona Community Player — Studio Admin v2.0

Full visual redesign across all seven admin screens: login, dashboard, website status, community profile, form builder, responses and operations. Single CSS design system: Manrope + DM Sans, navy navigation, violet accent, light layered canvas, consistent cards, buttons, fields, typography and responsive layouts. All existing JS, Firebase config, database rules, field IDs, form URLs and public pages are retained.

## Deploy
Backup existing site and database rules. Upload the contents of this ZIP to the site root, preserving folder structure. Purge CDN/browser cache and hard refresh. No Firebase rules migration is included. Check each screen and live auth/data operations on staging before replacing production.

## Important
This is a design-system overhaul, not a security audit or live Firebase verification. The older backend's authentication and permissions remain unchanged.
